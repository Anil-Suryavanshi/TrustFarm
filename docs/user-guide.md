# User guide

1. Start the API and dashboard using the README commands.
2. Open **Simulator** and choose a scenario to generate virtual readings.
3. Review **Overview** for the network decision and alerts.
4. Inspect per-sensor values on **Sensors** and factor scores on **Data quality**.
5. Change the demonstration threshold on **Decision support** if needed.
6. Run a labelled scenario from **Experiments** to calculate actual metrics.
7. Download the current simulated records from **Data management**.

`Reset data` intentionally clears the in-memory demo history. It does not delete any application source files.
