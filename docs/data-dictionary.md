# Data dictionary

| Field | Meaning |
|---|---|
| `reading_id` | Unique simulated record identifier |
| `sensor_id` | Virtual sensor identifier, e.g. `SENSOR_01` |
| `timestamp` | UTC ISO-8601 generated/delivered timestamp |
| `soil_moisture` | Simulated percentage; may be null for a missing fault |
| `temperature_c` | Simulated air temperature in °C |
| `humidity_pct` | Simulated relative humidity percentage |
| `scenario` | Condition selected for controlled simulation |
| `ground_truth_fault` | Evaluation-only injected-fault label |
| `quality_flags` | Data-quality observations generated by analysis |
| `data_source` | Always `simulated` in this release |
